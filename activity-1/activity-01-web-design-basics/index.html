About Web Design

Web design is the process of creating websites. It includes both the visual appearance and the functionality of a website.

A website is the whole collection of connected pages under one domain, while a webpage is a single page within that site. I think of a website like a whole book collection, and each webpage is one individual book on the shelf.

Key Web Design Concepts

HTML

HyperText Markup Language - the structure of web pages

CSS

Cascading Style Sheets - the styling of web pages

JavaScript

JavaScript - the behavior and interactivity of web pages

Practice

  • Build a simple webpage layout with HTML.
  • Use CSS to change colors, spacing, and text styles.
  • Try adding small interactive features with JavaScript.
