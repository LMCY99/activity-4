# Activity 02 — Introduction to HTML

> **🛠️ Stack for this lesson** — Vanilla HTML / CSS · open `index.html` in any browser.
> 📥 Template: [/learn/w1/template/activity-02-intro-to-html](/learn/w1/template/activity-02-intro-to-html)

A monthly-agenda starter with a working November section showing nested `<ol>` / `<ul>` / `<li>` structure. Your job is to extend it with a December section so the page reads like a real two-month plan.

**Time:** ~45 minutes · **Concept:** Concept 02 — Introduction to HTML

---

## What You'll Build

| # | TODO | File |
|---|------|------|
| 1 | A December list item with the same nested structure as November | `index.html` |
| 2 | A paragraph and link that points readers to a YouTube tutorial of your choice | `index.html` |

The November section is intentionally complete so you can study how `<ol>` → `<li>` → `<ul>` → `<li>` nests. There are no commented-out solutions for December — you write the markup yourself.

## Run It

```bash
open index.html
```

Or double-click `index.html` from your file explorer.

## Verify

Your activity is done when, in the browser:

- [ ] The page heading reads "My Monthly Agenda" and the browser tab shows the same title.
- [ ] Two numbered months (1. November, 2. December) appear with bold month names.
- [ ] Each month has three nested categories: Goals, To-dos, Events.
- [ ] December's content is *yours* — you can add real items, not just copy November's.
- [ ] An external link below the list opens a YouTube tutorial in a new tab when you click it.
- [ ] All tags are closed and the indentation makes the structure readable.

## Stretch

Pick one and note it in your reflection:
- Add a third month with at least one category that uses a different tag (`<dl>`, `<table>`, etc.).
- Style the months with different colors using inline CSS (a peek at Activity 03).
- Add a horizontal rule (`<hr>`) between months and explain why it does or doesn't help readability.
